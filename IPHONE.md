# Как подключить iPhone к УВЫ control

Ядро уже слушает порт **8486**. С телефона нужен обычный **http**, не https.

Адрес ядра:

`http://95.165.139.60:8486`

Токен — строка `API_TOKEN` из файла `.env` на сервере.

---

## 1. Проверка, что ядро открыто

На iPhone откройте **Safari** (не Chrome и не Telegram-браузер) и вставьте:

`http://95.165.139.60:8486/health`

Должно появиться:

```json
{"ok": true}
```

Если страница не открывается — с телефона нет доступа к порту 8486 (роутер, файрвол или мобильный интернет без белого IP). С Wi‑Fi на локации, если белый IP не открывается, используйте локальный адрес сервера, например `http://192.168.1.10:8486`.

---

## 2. Поставить как приложение на домашний экран

Быстрый вариант без установки IPA — файл остаётся ярлыком Safari.

Чтобы поставить **настоящее приложение с логотипом УВЫ с компьютера на iPhone**, смотрите **[IOS-INSTALL.md](IOS-INSTALL.md)**.

1. В Safari откройте `http://95.165.139.60:8486`
2. На экране входа введите:
   - URL ядра: `http://95.165.139.60:8486`
   - API токен из `.env`
3. Нажмите **Сохранить и открыть** — должен появиться список асиков.
4. Кнопка «Поделиться» (квадрат со стрелкой вверх) → **На экран «Домой»** → Добавить.
5. На домашнем экране появится иконка **УВЫ control**.

Дальше открывайте именно эту иконку, не ищите приложение в App Store.

Внутри можно:

- смотреть хэшрейт и время последнего пинга
- жать **Перезагрузить**
- включать/выключать авторебут

---

## 3. Пуши на iPhone

Сама иконка на домашнем экране пуши не шлёт. Для уведомлений:

1. App Store → приложение **ntfy**
2. Subscribe to topic — та же секретная тема, что в `.env` в `NTFY_TOPIC`
3. Когда хэшрейт упадёт или ядро уйдёт в ребут, на телефон придёт пуш

Либо оставьте Telegram-бота, если он уже прописан в `.env`.

---

## Если не пускает

| Что видите | Что сделать |
|---|---|
| Safari не открывает страницу | Проверьте `http://...:8486/health`. Нужен **http**, порт **8486** |
| «Неверный API токен» | Скопируйте `API_TOKEN` из `.env` на сервере, без пробелов |
| Пустой список / offline | Ядро запущено, но до асиков не достучалось — это уже `LOCATION_IP` и порты в `miners.json` |
| Со своей фермы белый IP не открывается | Впишите LAN-адрес сервера ядра |
