# Как поставить УВЫ control на iPhone с компьютера

Это полноценное приложение: своя иконка «УВЫ», своё имя на домашнем экране, открывается как обычная программа, не через Safari.

Mac не нужен. Сборка IPA идёт в облаке Expo, на iPhone приложение ставится с Windows по кабелю через **Sideloadly**.

---

## Что понадобится

1. Windows-ПК
2. iPhone и кабель Lightning / USB-C
3. Apple ID (обычная учётка iCloud; платная Developer-подписка не обязательна)
4. Node.js: https://nodejs.org (LTS)
5. Аккаунт Expo: https://expo.dev (бесплатно)
6. Sideloadly: https://sideloadly.io

Ограничение бесплатного Apple ID: приложение живёт **7 дней**, потом его нужно заново подписать через Sideloadly (2 минуты). С платной подпиской Apple Developer ($99/год) стоит год.

---

## Шаг 1. Собрать файл IPA на компьютере

Откройте командную строку:

```bat
cd C:\Users\Tkoma\Desktop\Apple\appant\ios-app
npm install
npm install -g eas-cli
eas login
eas init
eas build -p ios --profile preview
```

`eas init` спросит, создать ли проект — ответьте yes.

При первой сборке Expo попросит Apple ID. Введите тот же Apple ID, которым пользуетесь на iPhone.

Сборка занимает 10–20 минут. В конце в терминале или на https://expo.dev появится кнопка **Download**. Скачайте файл `УВЫ control.ipa` (или `uvy-control.ipa`) на компьютер, например на Рабочий стол.

---

## Шаг 2. Поставить IPA на iPhone с Windows

1. На iPhone: Настройки → **Основные** → **Передача или сброс iPhone** → выключите **Найти iPhone** на время установки (Sideloadly часто этого требует). После установки можно включить обратно.
2. Подключите iPhone кабелем к ПК. Если iPhone спросит «Доверять этому компьютеру?» — Доверять.
3. Установите и откройте **Sideloadly**.
4. В поле Apple ID введите свой Apple ID и пароль. Если включена двухфакторка — введите код с iPhone.
5. Перетащите скачанный `.ipa` в окно Sideloadly.
6. Нажмите **Start**. Дождитесь «Done».

---

## Шаг 3. Разрешить приложение на iPhone

1. Настройки → **Основные** → **VPN и управление устройством** (на новых iOS: **Основные** → **VPN и управление устройством** / **Профили**).
2. Найдите свой Apple ID → **Доверять**.
3. На iOS 16 и новее: Настройки → **Конфиденциальность и безопасность** → **Режим разработчика** → включить → перезагрузить iPhone → снова включить.

После этого на домашнем экране появится **УВЫ control** с логотипом. Открывается как обычное приложение.

---

## Шаг 4. Первый вход

В приложении:

- URL ядра: `http://95.165.139.60:8486` (именно **http**, порт **8486**)
- API токен: значение `API_TOKEN` из `.env` на сервере

Дальше — список асиков, хэшрейт, кнопка перезагрузки, авторебут.

---

## Если через 7 дней приложение перестало открываться

Это нормально для бесплатного Apple ID. Снова откройте Sideloadly, тот же IPA, тот же Apple ID, Start. Пересобирать IPA не нужно.

---

## Если что-то пошло не так

| Проблема | Что сделать |
|---|---|
| `eas build` просит Apple Developer | Для облачной сборки иногда нужна платная подписка. Тогда либо оформите её, либо поставьте приложение через Safari (файл `IPHONE.md`) |
| Sideloadly не видит iPhone | Поставьте iTunes / Apple Devices из Microsoft Store, разблокируйте телефон, нажмите «Доверять» |
| «Ненадёжный разработчик» | Шаг 3 — доверить профиль Apple ID |
| Приложение сразу закрывается | Включите Режим разработчика и перезагрузите iPhone |
| Нет связи с ядром | Только `http://95.165.139.60:8486`, не https |

Пуши надёжнее через **ntfy** (см. `IPHONE.md`), даже когда приложение закрыто.
